# Hi there, I'm Ojilong

### About Me
I'm a university student in Uganda studying education with a focus on biology and chemistry, and I'm training to become a bio/chem teacher. I'm also a self-taught programmer. I build tools and applications, from simple CLI tools to small desktop and Android apps, mostly to solve problems I run into myself. That drive comes from running into the limits of existing software and not being able to use it the way I want.

I'm interested in bringing coding and education together (edtech), and in contributing to Uganda's tech and education space. Several of my projects are study tools for reading, research and revision.

### How I Work
* I code on a modest setup: a Windows PC with a Celeron processor, and Termux on my Android phone. Because of this I prefer lightweight tools and small, well-scoped projects.
* I use AI as part of my workflow. The sections below are honest about where I used it heavily and where I'm writing the code myself.
